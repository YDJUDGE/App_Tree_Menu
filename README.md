Django Tree Menu App

Это приложение Django, реализующее древовидное меню в соответствии с заданными требованиями. Оно позволяет создавать, управлять и отображать несколько меню на веб-странице с использованием пользовательского шаблонного тега.
Возможности

    Древовидное меню: Поддерживает вложенные меню с отношениями родитель-потомок.
    Шаблонный тег: Меню отображаются с помощью тега {% draw_menu 'menu_name' %}.
    Автоматическое раскрытие: Все родительские элементы над активным пунктом меню раскрыты, а также первый уровень вложенности под активным пунктом.
    Хранение в БД: Элементы меню хранятся в базе данных SQLite.
    Интеграция с админкой Django: Меню можно управлять (создавать, редактировать, удалять) через стандартный интерфейс админки Django.
    Определение активного пункта: Активный пункт меню определяется на основе URL текущей страницы.
    Несколько меню на странице: На одной странице можно отобразить несколько меню, которые определяются по имени.
    Поддержка URL: Пункты меню могут ссылаться на явные URL или именованные URL (разрешаемые через reverse() в Django).
    Эффективные запросы к БД: Для отрисовки каждого меню используется ровно один запрос к базе данных.

Требования

    Python 3.8+
    Django 4.2+
    Используются только Django и стандартная библиотека Python, без дополнительных сторонних библиотек.

Запуск сервера

    Использовать команду python manage.py runserver
